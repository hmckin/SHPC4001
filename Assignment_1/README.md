A series of C programs simulating the trajectory of a bouncing ball.

## Files

### `bouncing.c` — Original Program
The base program.

### `bouncing2.c` — Exercise 1: Algorithm Fix
Fixes the two issues present in the original. Output is written to `bounce2.txt`.

### `bouncing3.c` — Exercise 3: Timestep
Investigates the effect of changing the timestep `dt`. Output is written to `bounce3.txt`.

### `bouncing4.c` — Exercise 4: Initial Conditions
Investigates the effect of varying initial position and velocity. Output is written to `bounce4.txt`.

### `bouncing5.c` — Exercise 5: Inelastic Bouncing
Investigates inelastic collision conditions. Output is written to `bounce5.txt`.

## Compilation + Plotting

Each program can be compiled and run:

```bash
gcc bouncing.c -o bouncing
./bouncing
```
Each plot can be generated by altering line 7 in plot_data.py to reference the correct txt file. With a venv including matplotlib and numpy run:

```bash
python plot_data.py
```
