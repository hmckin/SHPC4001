Plotting with Python + Matplotlib
=================================

1. Run:

```
bash setup_venv.sh
```

This creates a Python virtual environment .venv/ and installs required packages. You only need to do this once.

2. Activate the Python virtual environment. From the same folder do:

```
source .venv/bin/activate
```

3. Run the plot script.

```
python plot.py
```

4. To deactivate the environment

```
deactivate
```
